**OsintCat** builds tools and packages for **Open Source Intelligence (OSINT)** — helping researchers, analysts and developers gather and structure publicly available information efficiently.

- 🐍 **OsintCat.py** — our Python package for OSINT workflows
- 📦 **OsintCat.js** — our TypeScript/JavaScript package
- 🤖 Example bots & integrations for premium users
- 🕵️ Curated OSINT resource collections for the community
